# FOCUS MODE

**FOCUS MODE by ANI Studio** is an Android focus timer with an optional, user-enabled app distraction shield.

## Features
- 25, 45 and 60-minute sessions
- Select installed apps to redirect during active sessions
- Focus timer and completed-session counter
- Dark interface
- GitHub Actions APK build

## Build APK
Open **Actions → Build FOCUS MODE APK → Run workflow**. When it finishes, download the `FOCUS-MODE-debug-apk` artifact.

## App blocking and privacy
Blocking requires manually enabling the FOCUS MODE accessibility service in Android Settings. Android may limit enforcement and users can disable the service. The app does not upload usage data. Review the code before installing.
